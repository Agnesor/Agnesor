# Ilia Reutov

Product lead in Valencia, Spain. I take AI products from zero to production, and I build them spec-driven: a versioned PRD, a domain glossary and ADRs are the source of truth for parallel AI coding agents (Claude Code, opencode).

## Recent work

The product code is private. I'm happy to walk through the repos, specs and ADRs on a call.

- **Proxity - AI due-diligence engine.** A 13-stage pipeline that turns 2-3 analyst-days into a source-cited investment-committee report in under 30 minutes; agent loops kept to 2 of 13 stages; 101 ADRs; 8-14 production runs a day.
- **IInsider - AI pipeline and knowledge graph of the deal market.** From PRD to unattended production in 11 days, code written mostly by AI agents against my PRD, glossary, 25 ADRs and CI gates.
- **A&O Relocation.** A real-estate agency's Telegram listing feed turned into a searchable catalog with filters, map and translations; built and sold solo.
